## 一、信息安全是什么

- **定义**：保护信息的**保密性、完整性、可用性**及其他属性；为数据处理系统建立/采用技术、管理上的安全保护，使硬件、软件、数据不因偶然和恶意原因遭到破坏、更改、泄露。
- **常见问题**：计算机病毒泛滥、恶意软件入侵、黑客攻击、利用计算机犯罪、网络有害信息泛滥、个人隐私泄露等。

---

## 二、基本属性（CIA+）⭐⭐⭐

| 属性 | 含义 |
| --- | --- |
| <span style="white-space: nowrap;">**保密性**</span> | 信息只授权者享用，不泄露给未授权者 |
| <span style="white-space: nowrap;">**完整性**</span> | 信息从真实发信者到真实收信者，传输中未被非法添加/删除/替换 |
| <span style="white-space: nowrap;">**可用性**</span> | 信息和系统随时为授权者提供服务，合法使用不被无理拒绝 |
| <span style="white-space: nowrap;">**可控性**</span> | 管理者能对信息实施必要控制，对抗犯罪和外敌侵犯 |
| <span style="white-space: nowrap;">**不可否认性**</span> | 行为者对自己的信息行为负责，提供公证/仲裁证据 |

💡 记忆：**C I A + 可控 + 不可否认**（C=保密、I=完整、A=可用）。

---

## 三、信息安全的四个层次

| 层次 | 含义 |
| --- | --- |
| <span style="white-space: nowrap;">**设备安全**</span> | 物理设备安全 |
| <span style="white-space: nowrap;">**数据安全**</span> | 数据本身安全 |
| <span style="white-space: nowrap;">**内容安全**</span> | 信息内容合规安全 |
| <span style="white-space: nowrap;">**行为安全**</span> | 主体行为的安全 |

---

## 四、信息安全技术和措施 ⭐⭐

| 措施 | 要点 |
| --- | --- |
| <span style="white-space: nowrap;">**身份认证**</span> | 确认操作者身份：静态密码、智能卡、动态口令、USB Key、**PKI**、生物识别、虹膜等 |
| <span style="white-space: nowrap;">**访问控制**</span> | 防止未授权访问：自主访问控制 **DAC**、基于角色 **RBAC**、基于规则、强制访问控制 **MAC** |
| <span style="white-space: nowrap;">**入侵检测系统 IDS**</span> | 按安全策略监视网络/系统，发现攻击企图/行为/结果；分实时、事后检测 |
| <span style="white-space: nowrap;">**防火墙**</span> | 内/外网间安全网关；由服务访问规则、验证工具、包过滤、应用网关组成 |
| <span style="white-space: nowrap;">**网闸**</span> | 固态开关读写介质连接两独立主机；**无协议摆渡**，逻辑隔离阻断外部入侵 |
| <span style="white-space: nowrap;">**防病毒**</span> | 主动防范病毒；策略含检测、控制传播、清除、恢复等能力 |
| <span style="white-space: nowrap;">**数据加密**</span> | 对称加密（**DES**，密钥相同）/ 非对称加密（**RSA**，公私钥不同） |

---

## 五、安全行为分析技术 UEBA ⭐⭐

- **UEBA（用户和实体行为分析）**：提供用户画像及基于多种分析方法的异常检测，结合基本方法（签名规则、模式匹配、简单统计、阈值）和高级方法（监督/无监督机器学习），评估用户和实体（主机、应用、网络、数据库等）的异常活动。
- **架构三层**：数据获取层 → 算法分析层 → 场景应用层。

---

## 六、网络安全态势感知 ⭐⭐

- **是什么**：在大规模网络环境中，对引起态势变化的安全要素进行**获取、理解、显示，并预测未来趋势**；前提是**安全大数据**。
- **四项关键技术**：
  1. 海量多元异构数据的汇聚融合技术
  2. 面向多类型的网络安全威胁评估技术
  3. 网络安全态势评估与决策支撑技术
  4. 网络安全态势可视化

1. 信息安全的五个基本属性（CIA+）不包括（ ）（选择）
   A. 保密性  B. 完整性  C. 可用性  D. 可审计性（教材未列，属干扰项）

2. 下列属于"强制访问控制"缩写的是（ ）（选择）
   A. DAC  B. RBAC  C. MAC  D. PKI

3. 网闸（GAP）实现隔离的核心机制是（ ）（选择）
   A. 高速加密隧道  B. 无协议摆渡（固态开关读写介质）  C. 防火墙包过滤

4. 数据加密中，DES 和 RSA 分别代表哪种加密体制？

<details><summary>答案</summary>

1. **D**（五属性：保密性、完整性、可用性、可控性、不可否认性）
2. **C**（MAC=强制访问控制；DAC=自主；RBAC=基于角色；PKI=公钥基础设施）
3. **B**
4. **DES = 对称加密**（加解密密钥相同）；**RSA = 非对称加密**（公私钥不同，公钥可公开）

</details>
