## 一、硬件与软件是什么

- **计算机硬件**：计算机系统中由电子、机械和光电元件等组成的各种**物理装置**的总称，按系统结构要求构成有机整体，为软件运行提供物质基础。
- **计算机软件**：计算机系统中的**程序及其文档**。
- **关系**：硬件和软件**互相依存**——硬件是软件赖以工作的物质基础，软件的正常运作是硬件发挥作用的重要途径；两者协同发展、缺一不可（许多功能既可由硬件也可由软件实现）。

---

## 二、计算机硬件（冯·诺依曼结构）⭐⭐

现代计算机源于**冯·诺依曼计算机结构**，将硬件划分为**五部分**：

| 组成部分 | 说明 |
| --- | --- |
| <span style="white-space: nowrap;">**控制器**</span> | 指挥协调各部件工作 |
| <span style="white-space: nowrap;">**运算器**</span> | 算术与逻辑运算 |
| <span style="white-space: nowrap;">**存储器**</span> | 存放程序与数据 |
| <span style="white-space: nowrap;">**输入设备**</span> | 向计算机输入信息 |
| <span style="white-space: nowrap;">**输出设备**</span> | 输出处理结果 |

💡 现实整合：**控制器 + 运算器 = 中央处理器（CPU）**；输入设备与输出设备常集成为一体，按传输过程划分为总线、接口和外部设备。

---

## 三、计算机软件（两大类）⭐⭐

按所起作用和运行环境不同，软件分为**系统软件**和**应用软件**：

| 类别 | 作用 | 包含 |
| --- | --- | --- |
| <span style="white-space: nowrap;">**系统软件**</span> | 为整个计算机系统配置、不依赖特定应用领域的通用软件，控制管理软硬件资源、为其他软件服务 | 操作系统、**数据库**、**中间件**等 |
| <span style="white-space: nowrap;">**应用软件**</span> | 为某类应用需要或解决特定问题而设计（如图形图像、财务、游戏软件） | 分为**专用的应用软件**与**通用的应用软件** |

💡 选择题高频：**"只有系统软件作用下，硬件才能协调工作、应用软件才能运行"**；问"下列属于系统软件的是"→ 操作系统/数据库/中间件；"属于应用软件"→ 财务软件/游戏等。

## 四、本节自测

1. 冯·诺依曼计算机结构将硬件划分为五部分，其中控制器和运算器被集成为（ ）（选择）
   A. GPU  B. CPU  C. 内存  D. 主板

2. 下列软件中，属于系统软件的是（ ）（选择）
   A. 财务软件  B. 操作系统  C. 游戏软件  D. 图形处理软件

3. 关于硬件与软件的关系，下列说法正确的是（ ）（选择）
   A. 硬件可脱离软件独立发挥全部功能  B. 两者互相依存、协同发展  C. 软件是硬件的物质基础

4. 计算机硬件五部分中，负责"算术与逻辑运算"的是哪一部分？

<details><summary>答案</summary>

1. **B**（CPU = 控制器 + 运算器）
2. **B**（系统软件含操作系统、数据库、中间件；ACD 均为应用软件）
3. **B**
4. **运算器**

</details>
