## 一、计算机网络是什么

- **定义**：利用通信线路将地理上分散的、具有独立功能的计算机系统和通信设备按不同形式连接起来，依靠网络软件及通信协议实现**资源共享**和**信息传递**的系统。
- **功能**：数据通信、资源共享、管理集中化、实现分布式处理、负荷均衡。
- **分类**：
  - 按**作用范围**：个人局域网 PAN、局域网 LAN、城域网 MAN、广域网 WAN。
  - 按**使用者**：公用网（Public）、专用网（Private）。
- **基本网络设备**：集线器、中继器、网桥、交换机、路由器、防火墙。

## 二、网络协议分层（OSI vs TCP/IP）⭐⭐⭐

### 2.1 OSI 七层（自底向上）
| 层 | 名称 |
| --- | --- |
| <span style="white-space: nowrap;">**第1层**</span> | 物理层 |
| <span style="white-space: nowrap;">**第2层**</span> | 数据链路层 |
| <span style="white-space: nowrap;">**第3层**</span> | 网络层 |
| <span style="white-space: nowrap;">**第4层**</span> | 传输层 |
| <span style="white-space: nowrap;">**第5层**</span> | 会话层 |
| <span style="white-space: nowrap;">**第6层**</span> | 表示层 |
| <span style="white-space: nowrap;">**第7层**</span> | 应用层 |

### 2.2 TCP/IP 四层
| 层 | 名称 | 对应 OSI |
| --- | --- | --- |
| <span style="white-space: nowrap;">**网络接口层**</span> | 网络接口层 | 对应 OSI **下两层**（数据链路层 + 物理层） |
| <span style="white-space: nowrap;">**网际层**</span> | 网际层 | 对应 OSI 网络层（核心协议 **IP**） |
| <span style="white-space: nowrap;">**传输层**</span> | 传输层 | 对应 OSI 传输层（**TCP / UDP**） |
| <span style="white-space: nowrap;">**应用层**</span> | 应用层 | 对应 OSI **上三层**（应用 + 表示 + 会话） |

💡 关键对应：**TCP/IP 应用层 = OSI 上三层；TCP/IP 网络接口层 = OSI 下两层**。
💡 TCP/IP 协议族：IP、TCP、UDP、TELNET、FTP、SMTP、NNTP、HTTP 等。
💡 IEEE 802 族：802.3（以太网 CSMA/CD）、802.5（令牌环）、**802.11（无线局域网 WLAN）**。

### 2.3 各层典型协议对照 ⭐⭐⭐（本节能出"下列协议属于哪一层"）

#### OSI 七层逐层：协议 / 设备 / 传输单位
| 层 | 名称 | 典型协议 / 标准 | 典型设备 | 传输单位（PDU） |
| --- | --- | --- | --- | --- |
| <span style="white-space: nowrap;">**第1层**</span> | 物理层 | RS-232、RS-449、RJ-45、IEEE 802.3（物理规范）、光纤接口 | 集线器、中继器 | 比特（bit） |
| <span style="white-space: nowrap;">**第2层**</span> | 数据链路层 | PPP、HDLC、SLIP、以太网（802.3 MAC）、802.11（WLAN MAC） | 网桥、二层交换机 | 帧（frame） |
| <span style="white-space: nowrap;">**第3层**</span> | 网络层 | IP、ICMP、IGMP、OSPF、BGP、RIP、（ARP*） | 路由器、三层交换机 | 分组/包（packet） |
| <span style="white-space: nowrap;">**第4层**</span> | 传输层 | TCP、UDP | 防火墙（常工作至此） | 段/报文（segment） |
| <span style="white-space: nowrap;">**第5层**</span> | 会话层 | RPC、NetBIOS、NFS（会话部分） | — | 会话（SP） |
| <span style="white-space: nowrap;">**第6层**</span> | 表示层 | SSL/TLS、JPEG、MPEG、ASCII、加密压缩 | — | 表示（PP） |
| <span style="white-space: nowrap;">**第7层**</span> | 应用层 | HTTP、HTTPS、FTP、SMTP、POP3、IMAP、DNS、DHCP、TELNET、SNMP、NNTP | 应用网关 | 报文（message） |

> *ARP/RARP 位置有争议：TCP/IP 体系中常划归**网络接口层/链路层**（介于数据链路与网络层之间）；软考偶有将其归"网络层"的考法，见到即可，不必纠结。

#### TCP/IP 四层逐层协议
| 层 | 典型协议 | 说明 |
| --- | --- | --- |
| <span style="white-space: nowrap;">**网络接口层**</span> | Ethernet（802.3）、Wi-Fi（802.11）、PPP、HDLC、SLIP、ARP、RARP | 对应 OSI 下两层，负责相邻节点间帧传输 |
| <span style="white-space: nowrap;">**网际层**</span> | IP、ICMP、IGMP、OSPF、BGP、RIP | 核心 IP，负责路由与寻址 |
| <span style="white-space: nowrap;">**传输层**</span> | TCP、UDP | TCP 面向连接、可靠；UDP 无连接、高效 |
| <span style="white-space: nowrap;">**应用层**</span> | HTTP、HTTPS、FTP、SMTP、POP3、IMAP、DNS、DHCP、TELNET、SNMP、TFTP、NTP | 对应 OSI 上三层，直接服务应用 |

💡 **速记口诀**（自下而上高频）：
- 网络层认 **IP / ICMP / IGMP / 路由协议**；传输层认 **TCP / UDP**；应用层认 **HTTP / FTP / DNS / SMTP / TELNET**。
- 考"属于网络层"→ 选 IP 类；考"属于传输层"→ 选 TCP/UDP；考"属于应用层"→ 选 HTTP/FTP/DNS 等。

## 三、网络性能指标 ⭐⭐

| 指标 | 含义 |
| --- | --- |
| <span style="white-space: nowrap;">**速率**</span> | 主机/设备在数字信道上传送数据的速率（b/s，比特每秒），最重要指标 |
| <span style="white-space: nowrap;">**带宽**</span> | 单位时间内网络两点间所能通过的"最高数据率"（b/s） |
| <span style="white-space: nowrap;">**吞吐量**</span> | 单位时间内通过某网络/信道/接口的数据量，受带宽限制 |
| <span style="white-space: nowrap;">**时延**</span> | 数据一端传到另一端所需时间 = 发送时延 + 传播时延 + 处理时延 + 排队时延 |
| <span style="white-space: nowrap;">**往返时间 RTT**</span> | 发送方发数据到收到接收方确认的总时间 |
| <span style="white-space: nowrap;">**利用率**</span> | 信道利用率（有数据通过的概率）+ 网络利用率（加权平均） |

**非性能指标**：费用、标准化、可靠性、可扩展性/可升级性、易管理性和可维护性。

## 四、软件定义网络 SDN ⭐⭐

- **核心思想**：**控制面与数据面分离**，通过软件编程定义和控制网络，实现流量灵活控制、网络更智能。
- **架构（由下到上 / 由南到北）**：**数据平面 → 控制平面 → 应用平面**。
  - **控制平面**：逻辑中心化、可编程的**控制器**，掌握全局网络信息。
  - **数据平面**：哑交换机（仅简单转发），按控制器下发的规则动作。
  - 两层间用开放统一接口（如 **OpenFlow**）交互。
- **南北向 / 东西向**开放接口，使网络管理更简单、动态、灵活。

## 五、5G 三大应用场景 ⭐⭐⭐

5G = **高速率、低时延、大连接** 的新一代移动通信技术，重点满足灵活多样的物联网需要。

| 场景 | 英文 | 含义 | 典型应用 |
| --- | --- | --- | --- |
| <span style="white-space: nowrap;">**eMBB**</span> | enhanced Mobile Broadband | 增强移动宽带 | 移动互联网体验、高清视频 |
| <span style="white-space: nowrap;">**uRLLC**</span> | ultra-Reliable Low-Latency Communication | 超高可靠低时延通信 | 工业控制、自动驾驶、远程医疗 |
| <span style="white-space: nowrap;">**mMTC**</span> | massive Machine-Type Communication | 海量机器类通信 | 智慧城市、智能家居、传感采集 |

   A. 发送 + 传播 + 处理 + 排队  B. 仅发送 + 传播  C. 编码 + 解码  D. 路由 + 交换

4. 5G 的三大应用场景 eMBB、uRLLC、mMTC 分别代表什么含义？

5. SDN（软件定义网络）最核心的思想是什么？（控制面与数据面的关系）

6. 下列协议中，属于 OSI 网络层的是（ ）（选择）
   A. TCP  B. IP  C. HTTP  D. Ethernet

7. 下列协议中，工作于 TCP/IP 应用层的是（ ）（选择）
   A. IP  B. TCP  C. DNS  D. ARP

<details><summary>答案</summary>

1. **B**
2. **B**（IP 属网际层；HTTP/FTP 属应用层）
3. **A**
4. **eMBB**＝增强移动宽带；**uRLLC**＝超高可靠低时延通信；**mMTC**＝海量机器类通信
5. **控制面与数据面分离**：控制器（逻辑中心化、可编程）掌握全局，数据层哑交换机仅按规则转发，两层间用 OpenFlow 等开放接口交互
6. **B**（TCP 属传输层；HTTP 属应用层；Ethernet 属数据链路层）
7. **C**（IP 属网际层；TCP 属传输层；ARP 属网络接口层/链路层）
