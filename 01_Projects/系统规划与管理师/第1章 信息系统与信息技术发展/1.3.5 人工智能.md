## 一、人工智能是什么

- **定义**：利用计算机或计算机控制的机器来**模拟、延伸和扩展人类的智能**，从而获取知识并使用知识获得最佳结果的理论、方法、技术及应用系统。
- **提出**：1956 年。当前随大数据、高性能计算、深度学习进入新一轮热潮。

---

## 二、三大特点 ⭐⭐

| 特点 | 含义 |
| --- | --- |
| <span style="white-space: nowrap;">**① 人本、计算、数据**</span> | 由人类设计、为人类服务，本质为计算，基础为数据 |
| <span style="white-space: nowrap;">**② 感知交互互补**</span> | 能感知环境、产生反应、与人交互、与人互补 |
| <span style="white-space: nowrap;">**③ 适应演化扩展**</span> | 有适应特性、学习能力、演化迭代、连接扩展 |

---

## 三、关键技术（重点分类）⭐⭐⭐

| 技术 | 要点 |
| --- | --- |
| <span style="white-space: nowrap;">**机器学习**</span> | 自动将模型与数据匹配并"学习"；含符号学习、连接学习、统计机器学习；神经网络/深度学习 |
| <span style="white-space: nowrap;">**自然语言处理 NLP**</span> | 机器翻译、语义理解、问答系统、舆情监测、语音识别、OCR 等 |
| <span style="white-space: nowrap;">**计算机视觉 CV**</span> | 让计算机拥有类似人类的图像提取/处理/理解能力；应用于自动驾驶、医疗等 |
| <span style="white-space: nowrap;">**知识图谱**</span> | 结构化语义知识库，由"结点+边"组成的关系网络 |
| <span style="white-space: nowrap;">**专家系统**</span> | 见下方"六部分"（必背） |
| <span style="white-space: nowrap;">**人机交互 HCI**</span> | 人与计算机的信息交换（含语音/情感/体感/脑机交互） |
| <span style="white-space: nowrap;">**机器思维/感知/行为**</span> | 模拟推理搜索规划 / 机器视觉与 NLP / 智能控制与制造 |
| <span style="white-space: nowrap;">**计算智能**</span> | 神经计算、进化计算、模糊计算 |
| <span style="white-space: nowrap;">**分布智能**</span> | 分布式问题求解、多代理系统 |
| <span style="white-space: nowrap;">**人工心理/情感**</span> | 研究心理情感对认知的影响 |
| <span style="white-space: nowrap;">**大模型**</span> | 参数庞大的模型（数百万到数十亿），通常由深度神经网络构建 |

---

## 四、专家系统六部分（必背）⭐⭐⭐

> 专家系统 = 模拟人类专家解决领域问题的计算机程序系统，内部含大量领域专家水平的知识与经验。

| 组成部分 | 作用 |
| --- | --- |
| <span style="white-space: nowrap;">**人机交互界面**</span> | 与用户交互 |
| <span style="white-space: nowrap;">**知识库**</span> | 存储领域知识与经验 |
| <span style="white-space: nowrap;">**推理机**</span> | 根据知识进行推理判断 |
| <span style="white-space: nowrap;">**解释器**</span> | 解释推理过程与结果 |
| <span style="white-space: nowrap;">**综合数据库**</span> | 存放当前问题的已知事实/中间结果 |
| <span style="white-space: nowrap;">**知识获取**</span> | 从专家/数据中提取知识存入知识库 |

💡 记忆：**界库理释数获**（界面、知识库、推理机、解释器、综合数据库、知识获取）。

---

## 五、应用与发展趋势

- 拐点：从"不能用"到"可以用"，距"很好用"仍有瓶颈。
- 趋势：①人机混合智能；②自主智能系统（减少人工干预）；③与其他学科交叉渗透；④产业蓬勃发展（"人工智能+X"）；⑤人工智能社会学（法规与风险治理）。

   A. 自然语言处理  B. 计算机视觉 CV  C. 知识图谱  D. 人机交互

3. 人工智能的三大特点中，强调"本质为计算、基础为数据、为人类服务"的是第几点？

4. 大模型通常具有什么特点？（参数规模）

<details><summary>答案</summary>

1. **C**（专家系统六部分：人机交互界面、知识库、推理机、解释器、综合数据库、知识获取；不含操作系统）
2. **B**（CV 用于图像理解、自动驾驶等）
3. **第①点**（由人类设计、为人类服务，本质为计算，基础为数据）
4. **模型参数数量庞大**（数百万到数十亿参数），通常由深度神经网络构建
