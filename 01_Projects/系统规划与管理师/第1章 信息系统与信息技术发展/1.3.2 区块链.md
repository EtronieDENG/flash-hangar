## 一、区块链是什么

- **狭义**：一种按时间顺序将数据区块以顺序相连组合的**链式数据结构**，并以密码学方式保证**不可篡改、不可伪造**的**分布式账本**。
- **广义**：利用块链式数据结构来验证与存储数据、利用分布式节点生成更新数据、利用共识算法保证安全的技术。
- 核心：**分布式账本**——交易记账由分布在不同节点的"记账节点"共同完成。

---

## 二、七大特点 ⭐⭐

| 特点 | 要点 |
| --- | --- |
| <span style="white-space: nowrap;">**多中心化**</span> | 无单一中心控制 |
| <span style="white-space: nowrap;">**多方维护**</span> | 多个节点共同维护账本 |
| <span style="white-space: nowrap;">**时序数据**</span> | 带时间戳的链式结构存储 |
| <span style="white-space: nowrap;">**智能合约**</span> | 灵活可变的脚本代码，支持新型智能合约 |
| <span style="white-space: nowrap;">**不可篡改**</span> | 相邻区块相互验证，篡改需重算其后所有哈希，代价巨大 |
| <span style="white-space: nowrap;">**开放共识**</span> | 任意节点可参与，共识算法抵御攻击 |
| <span style="white-space: nowrap;">**安全可信**</span> | 密码学 + 共识保障链上数据安全 |

---

## 三、加密与共识（必考）⭐⭐⭐

- **加密算法**：
  - 散列（哈希）算法：MD5、SHA、**SM3**；目前区块链主要使用 **SHA256**。
  - 非对称加密：保障传输、存储、修改过程中的安全。
- **共识机制**（解决"记账权"问题）：**PoW、PoS、DPoS、Paxos、PBFT** 等。

💡 记忆：**不可篡改 = 链式结构 + 哈希递归验证（SHA256） + 共识机制**。

---

## 四、应用与趋势

- 应用：金融服务创新、供应链管理、数据安全与隐私保护等。
- 趋势：有望成为互联网基础协议之一（类比 TCP/IP）；不同分层承载不同功能；应用呈螺旋式上升。
