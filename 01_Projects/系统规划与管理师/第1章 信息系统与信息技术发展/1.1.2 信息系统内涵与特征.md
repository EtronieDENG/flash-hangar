## 一、信息系统是什么（定义：狭义 + 广义）

**先分清两个概念**
- **信息化**（1.1.1）：广义过程，涉及社会各领域信息技术的应用和发展。
- **信息系统**：实现信息化目标的**具体手段**，是信息化中具体的技术和管理实践。

**① 狭义定义（教材原话，重点）⭐⭐⭐**
> 由**计算机硬件、网络和通信设备、软件、信息资源、信息用户和规章制度**组成的，以**处理信息流为目的的人机一体化系统**。
> 任务：对原始数据进行**收集、加工、存储**并加工产生有价值的信息，以不同方式提供给各类用户使用。

**② 广义定义**
> 包含组织内和组织所处环境中的重要**人员、地点和事情**的信息，通过**输入、处理、输出**三个基本活动将原始数据转变为有用的信息；具有**决策支持、协调、控制、协助管理者与员工分析问题、可视化复杂对象、创造新产品**等功能。

💡 一句话记：**狭义＝人机一体化系统（6 要素）；广义＝输入—处理—输出 + 决策支持等功能**。

---

## 二、核心是什么 ⭐⭐⭐（必背）

教材给出的"以计算机为基础的信息系统"定义，揭示了它的核心：

> 结合**管理理论和方法**，应用**信息技术**解决管理问题、提高生产效率，为生产/信息化过程以及管理和决策提供支撑的系统。
> 信息系统 ＝ **管理模型 + 信息处理模型 + 系统实现条件** 的结合。

- **管理模型**：系统服务对象领域的专门知识、分析处理该领域问题的模型（又称"对象的处理模型"）。
- **信息处理模型**：系统处理信息的结构和方法（把管理模型的理论转化为信息获取、存储、传输、加工、使用的规则）。
- **系统实现条件**：可用的计算机/通信技术、从事对象领域工作的人员，以及对这些资源的控制与融合。

💡 记忆：**信息系统不是纯技术，而是"管理 + 信息技术 + 实现条件"三者的结合**，落脚点是"支撑管理和决策"。

---

## 三、包括了什么（构成要素）

从三个口径理解"信息系统由什么组成"：

**口径 A：狭义 6 要素（人机一体化）⭐⭐⭐**
| 要素 | 说明 |
| --- | --- |
| <span style="white-space: nowrap;">**计算机硬件**</span> | 主机、外设等实体 |
| <span style="white-space: nowrap;">**网络和通信设备**</span> | 传输与互联 |
| <span style="white-space: nowrap;">**软件**</span> | 系统软件、应用软件 |
| <span style="white-space: nowrap;">**信息资源**</span> | 数据、知识等 |
| <span style="white-space: nowrap;">**信息用户**</span> | 使用系统的人员 |
| <span style="white-space: nowrap;">**规章制度**</span> | 管理规范与流程 |

**口径 B：广义 三维度**
| 维度 | 含义 |
| --- | --- |
| <span style="white-space: nowrap;">**组织**</span> | 人员、地点、事情等组织要素 |
| <span style="white-space: nowrap;">**管理**</span> | 管理模型、管理问题 |
| <span style="white-space: nowrap;">**信息技术**</span> | 信息处理的技术手段 |

**口径 C：抽象模型的组成部件**
> 硬件、软件、数据库、网络、存储设备、感知设备、外设、人员，以及把数据处理成信息的**规程**等。

💡 选择题高频：问"下列不属于信息系统组成的是"，干扰项常放"资金/利润/市场"等非组成要素。

---

## 四、信息系统的特征（8 个）⭐⭐

教材明确列了 8 个特征，注意"下列哪项**不属于**信息系统特征"的反选题型：

| 特征 | 要点 |
| --- | --- |
| <span style="white-space: nowrap;">**复杂性**</span> | 多子系统（硬件/软件/数据/网络）相互关联影响 |
| <span style="white-space: nowrap;">**动态性**</span> | 需不断调整改进，适应环境变化与业务需求发展 |
| <span style="white-space: nowrap;">**可扩展性**</span> | 可升级、扩展或重组 |
| <span style="white-space: nowrap;">**易用性**</span> | 简单方便，提高使用效率 |
| <span style="white-space: nowrap;">**实时性**</span> | 对实时数据快速处理响应，支撑决策 |
| <span style="white-space: nowrap;">**安全性**</span> | 保证完整性、可用性、机密性，防未授权访问 |
| <span style="white-space: nowrap;">**可靠性**</span> | 稳定可靠运行，避免故障造成损失 |
| <span style="white-space: nowrap;">**成本效益**</span> | 成本与收益保持合理比例 |

💡 口诀：**复动可易实，安可成**（复=复杂、动=动态、可=可扩展、易=易用、实=实时、安=安全、可=可靠、成=成本效益）。

---

## 五、信息系统抽象模型

- 简单说：通过**输入数据 → 加工处理 → 产生信息**的系统。
- 面向管理和支持生产是其显著特点。
- 组成（见"三、口径 C"）：硬件、软件、数据库、网络、存储、感知设备、外设、人员、规程。

---

## 六、信息系统生命周期（5 阶段）⭐⭐⭐（必背，几乎必考）

为工程化需要，把"产生—建设—运行—完善"的循环划分为典型阶段，称为信息系统生命周期。可**借用软件生命周期**来表示：

| 信息系统生命周期阶段 | 对应的软件生命周期阶段 | 主要目标/工作 |
| --- | --- | --- |
| <span style="white-space: nowrap;">**系统规划**</span> | 可行性分析与项目开发计划 | 定目标、可行性、总体计划 |
| <span style="white-space: nowrap;">**系统分析**</span> | 需求分析 | 明确需求 |
| <span style="white-space: nowrap;">**系统设计**</span> | 概要设计、详细设计 | 架构与详细方案 |
| <span style="white-space: nowrap;">**系统实施**</span> | 编码、测试 | 开发实现 |
| <span style="white-space: nowrap;">**系统运行和维护**</span> | 维护 | 上线运行、持续维护 |

💡 记忆：**规分设实施维**（规划→分析→设计→实施→运行维护）。常考"下一个阶段是？""某工作属于哪个阶段"。

## 七、信息系统的结构（物理结构 + 逻辑结构）⭐⭐

### 7.1 物理结构（硬件空间分布）

| 结构 | 含义 | 优点 | 缺点 |
| --- | --- | --- | --- |
| <span style="white-space: nowrap;">**集中式**</span> | 物理资源空间上集中配置（早期单机、多用户终端共享） | 资源集中、便于管理、利用率高 | 规模扩大后难维护；主机故障则全瘫（脆弱性） |
| <span style="white-space: nowrap;">**分布式**</span> | 通过网络把异地硬件/软件/数据联起来共享；可统一管理也可本地独立运作 | 顺应组织扁平化/网络化；易扩展、安全性好、单点故障不致命 | 资源分散、标准难统一、协调困难 |

💡 结论：**分布式已成为信息系统的主流模式**。

### 7.2 逻辑结构（通用五层，自底向上）⭐⭐⭐

结合主流的分布式物理结构，逻辑上通用结构**自底向上**分为五层：

| 层（自底向上） | 名称 | 职责 |
| --- | --- | --- |
| <span style="white-space: nowrap;">**第1层**</span> | **基础设施层** | 底层技术基础：信息感知设备、网络传输设备、存储设备 |
| <span style="white-space: nowrap;">**第2层**</span> | **资源管理层** | 操作系统、数据库等，负责资源管理与调度 |
| <span style="white-space: nowrap;">**第3层**</span> | **中间件层** | 保障信息（数据）传输与共享，提供基础数据服务（传输/交易/GIS中间件、J2EE架构） |
| <span style="white-space: nowrap;">**第4层**</span> | **业务逻辑层** | 创建业务流程驱动引擎（工作流引擎、报表引擎、交易处理引擎） |
| <span style="white-space: nowrap;">**第5层**</span> | **应用表现层** | 用户交互界面（UI 设计，在客户端展示信息） |

💡 记忆（自底向上）：**基资中业应**（基础设施→资源→中间件→业务→应用）。常考"某一描述属于哪一层"。

## 📝 本节自测（先盖住答案做，做完发我判分）

1. 狭义地说，信息系统是由若干要素组成的人机一体化系统，下列**不属于**其组成要素的是（ ）（选择）
   A. 计算机硬件  B. 信息资源  C. 规章制度  D. 市场利润

2. 以计算机为基础的信息系统，其核心是三个模型的结合，下列哪项**不在**其中（ ）（选择）
   A. 管理模型  B. 信息处理模型  C. 系统实现条件  D. 财务模型

3. 信息系统生命周期可借用软件生命周期表示，其五个阶段按顺序是（ ）（选择）
   A. 系统规划→系统分析→系统设计→系统实施→系统运行和维护
   B. 系统分析→系统规划→系统设计→系统实施→系统维护
   C. 系统设计→系统分析→系统规划→系统实施→系统运行和维护

4. 信息系统的逻辑结构（通用五层，自底向上）中，负责"用户交互界面（UI）"的是（ ）（选择）
   A. 基础设施层  B. 资源管理层  C. 中间件层  D. 应用表现层

5. 关于集中式与分布式物理结构，下列说法正确的是（ ）（选择）
   A. 集中式资源分散、标准易统一
   B. 分布式已成为信息系统的主流模式，单点故障不会导致整个系统停止
   C. 集中式一旦主机故障不影响其他节点
   D. 分布式不利于用户需求变化

6. 信息系统具有 8 个特征，请列出其中任意 5 个。

<details><summary>答案</summary>

1. **D**（狭义 6 要素：硬件、网络和通信设备、软件、信息资源、信息用户、规章制度；市场利润不是组成要素）
2. **D**（三结合＝管理模型 + 信息处理模型 + 系统实现条件）
3. **A**（规分设实施维）
4. **D**（应用表现层负责 UI/客户端展示）
5. **B**（A 说反了，集中式才资源集中；C 错，集中式主机故障全瘫；D 错，分布式正好便于应变）
6. 复杂性、动态性、可扩展性、易用性、实时性、安全性、可靠性、成本效益（任写 5 个即可）
