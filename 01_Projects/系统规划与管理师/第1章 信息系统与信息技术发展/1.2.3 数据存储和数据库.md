## 一、数据存储技术架构（五个组成部分）

从底层到上层由五部分组成：

| 组成 | 内容 |
| --- | --- |
| <span style="white-space: nowrap;">**存储介质**</span> | 机械硬盘 HDD、固态硬盘 SSD、磁带、光盘 |
| <span style="white-space: nowrap;">**组网方式**</span> | IP 组网、FC 光纤组网、IB 无线带宽组网 |
| <span style="white-space: nowrap;">**存储类型和协议**</span> | 文件存储、块存储、对象存储 |
| <span style="white-space: nowrap;">**存储架构**</span> | 集中式存储、分布式存储（存储集群） |
| <span style="white-space: nowrap;">**连接方式**</span> | **DAS / NAS / SAN**（见下） |

## 二、DAS / NAS / SAN 对比（必考）⭐⭐⭐

| 维度 | <span style="white-space: nowrap;">**DAS**</span> | <span style="white-space: nowrap;">**NAS**</span> | <span style="white-space: nowrap;">**SAN**</span> |
| --- | --- | --- | --- |
| 全称 | 直接附加存储 | 网络接入存储 | 存储区域网络 |
| 传输协议 | SCSI / FC / ATA | TCP/IP | FC（光纤通道） |
| 传输对象 | **数据块** | **文件** | **数据块** |
| 文件共享 | 否（主机自管文件系统） | 是（NFS/CIFS） | 否 |
| 异种 OS 共享 | 否 | 是 | 否 |
| 安装难易 | 不一定 | **简单** | **困难** |
| 灾难忍受度 | 低 | 高 | 高（专有方案） |
| 适合对象 | 中小组织 / SOHO / 服务器少 | 文档共享高、异质格式 | 大型组织 / 数据中心 / 数据库 |
| 容量扩充 | 低 | 中 | 高 |

💡 一句话区分：**DAS 直连主机难共享；NAS 走 TCP/IP 以文件共享、易用；SAN 用 FC 建高速专用存储网、适合大型数据库**。

---

## 三、数据结构模型（三种）⭐⭐

| 模型 | 结构 | 特点 |
| --- | --- | --- |
| <span style="white-space: nowrap;">**层次模型**</span> | 树结构 | 最早使用，实体间用"树"表示关联 |
| <span style="white-space: nowrap;">**网状模型**</span> | 有向图 | 实体间"多对多"关联 |
| <span style="white-space: nowrap;">**关系模型**</span> | 二维表 | **主流**，用表表示实体及关联 |

💡 层次模型 + 网状模型 统称为**格式化数据模型**。

---

## 四、关系型 vs NoSQL ⭐⭐

- **关系型数据库（ACID）**：基于关系模型，事务特性强（原子性、一致性、隔离性、持久性）。
- **NoSQL（非关系型）**：不需要固定表结构、通常无连接操作；含**键值、列存储、文档、图**等类型；**高并发、易扩展**，但事务能力较弱；在大数据存取上有关系型无法比拟的性能优势。

---

## 五、数据仓库（了解）

- 定义：面向主题的、集成的、非易失的、随时间变化的数据集合。
- 分类：ROLAP（基于关系库）、MOLAP（基于多维库）、HOLAP（混合）。

   A. 层次模型  B. 网状模型  C. 关系模型（二维表）  D. 格式化模型

4. 关系型数据库与 NoSQL 的主要区别是什么？（各举一关键词）

1. **B**（NAS：TCP/IP + 文件 + 异种 OS 共享）
2. **B**（SAN：FC、数据块、高速专用网；A 是 NAS，C 是 DAS）
3. **C**
4. 关系型基于关系模型、事务强（ACID）；NoSQL 无固定表结构、高并发易扩展但事务弱（如键值/列存储/文档/图）
