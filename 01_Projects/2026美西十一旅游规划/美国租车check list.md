### 一、 取车前与手续检查（柜台/停车场）

- [ ] **确认订单金额**：核对取车小票/合同上的最终金额是否为 **$479.33** 左右（确保没有被柜台人员偷加 PERS、补充保险或强行升级车型的费用）。
    
- [ ] **驾照与信用卡**：主驾驶员护照、中国驾照原件、驾照翻译件/国际驾照认证件（IDP）、主驾驶员名下的 Master/Visa 信用卡。
    

### 二、 车辆外观与轮胎物理检查（拍照/录像）

- [ ] **车身四周环视**：顺时针绕车一周，用手机**录一段高清视频**（重点拍前后保险杠、车门下方、后视镜、车顶等易刮蹭部位）。
    
- [ ] **轮胎胎纹与胎壁**：
    
    - [ ] 检查四个轮胎的**胎纹深度**（如果磨损到警戒线，直接要求换车）。
        
    - [ ] 检查**胎壁两侧**是否有鼓包、裂纹或严重划痕。
        
    - [ ] 检查轮毂是否有深度磕碰。
        
- [ ] **玻璃与灯光**：检查挡风玻璃是否有石子崩出的小裂痕；检查前后大灯、转向灯是否正常发光。
    

### 三、 车内与仪表盘检查（点火启动）

- [ ] **仪表盘警告灯**：点火后确认是否有发动机故障灯、胎压报警灯（TPMS）亮起。
    
- [ ] **油量/电量**：拍下油表，确认是否为**满油（Full Tank）**，并记录**初始总里程数**（Odometer）。
    
- [ ] **胎压监测**：在仪表盘菜单里调出四轮胎压数值，确认气压是否均衡（一般在 32-35 PSI 左右）。
    
- [ ] **后备箱工具**：打开后备箱底板，确认是否有**备胎（或补胎液/气泵）**以及**千斤顶、套筒螺丝扳手**。
    
- [ ] **基础设备**：测试倒车影像、空调冷暖风、CarPlay / 蓝牙连接是否正常。
    

### 四、 离场前的“拍照交检查”清单（发给我看）

在出口闸机开出去之前，拍下以下 **4 张核心照片**发给我：

1. [ ] **仪表盘全景图**（需清清晰看见：油表、总里程、无报警灯）。
    
2. [ ] **四轮轮胎特写图**（近距离拍一下轮胎侧面和胎纹）。
    
3. [ ] **车辆左前/右后 45 度外观图**（整体车况）。
    
4. [ ] **取车出闸小票/合同纸的终单金额**。
    

### 五、 补充：还车时快速 Check

- [ ] **加满油**：在 LAX 机场附近 3-5 英里内的加油站加满油，**保留加油小票**（防止被误扣高价油费）。
    
- [ ] **车内遗留物**：检查副驾手套箱、车门储物槽、后备箱、后座下方，确保手机、护照、钱包等随身物品无遗漏。
    
- [ ] **还车拍摄**：停好车后，再次拍下**仪表盘（油表+里程）**以及**车身四周**，并索取电子版/纸质还车凭证（Receipt）。
